# 吉大物流 UI 上线更新

本次更新包为 `releases/jida-ui-20261010.sh`，内含 10 个界面与品牌文件。它使用线上已有依赖重新构建，不安装新依赖、不执行数据库迁移，不覆盖 `.env`、账号数据库、私有上传文件或业务服务。完整文件清单与校验值见 `releases/jida-ui-20261010-manifest.json`。

## 执行更新

在本机 Windows PowerShell 执行，按提示输入服务器登录密码：

```powershell
$serverIp = Read-Host "请输入服务器公网 IP 或 SSH 主机名"
scp ".\releases\jida-ui-20261010.sh" "root@${serverIp}:/root/"
```

然后在服务器的 root 终端执行：

```bash
bash /root/jida-ui-20261010.sh
```

脚本核对现有 `zhiye` 服务、`/opt/zhiye` 部署目录、Node 版本和更新文件校验值，备份旧界面与旧构建后暂停网站、构建新版本，再启动并检查首页、主题脚本和品牌图片。构建期间网站会短暂不可用。不要与其他服务器更新同时执行。

出现 `UI_UPDATE_OK` 表示服务器内部检查通过。接着打开自己的实际网站地址，刷新页面，确认左上角品牌、浅色与暗色切换，以及暗色标志的闪光效果。主题选择应在刷新后保留。

## 失败恢复

构建失败、类型检查失败、启动或首页检查失败，脚本自动恢复旧界面和旧构建并启动网站。备份目录为 `/opt/zhiye-ui-backups/<时间>-<进程号>`，终端会打印实际路径；保留该目录。

如果服务器断电或进程被强制结束，EXIT 恢复流程无法执行。不要继续反复更新，先根据终端显示的备份目录恢复旧构建和界面。不会覆盖账号、资料或 `.env`。
