面向物流管理与计算机科学与技术双学位，本次更新包含专业项目库、GitHub 项目存储，以及资料库 PDF 按页提问。

## 专业项目库

导航新增“专业项目库”，支持列表、搜索、课程 / 标签筛选。项目页展示介绍、作者、技术标签、文件目录、代码、版本和讨论。运行说明建议写在项目包的 README，README 和代码均以纯文本显示。

审批通过的成员可以上传源代码 ZIP；作者和管理员可以更新项目并填写版本说明。每次 ZIP 及解压后全部文件总量分别不超过 200MB（200×1024×1024 字节），包内单个文件不超过 100MiB（GitHub 普通仓库文件限制），最多 1000 个条目，文件和显式目录都计数。依赖目录、编译产物、密码密钥和 GitHub 自动执行工作流不会导入，但这些文件仍计入解压总量。代码用于浏览与下载，首版不在线运行。原有资料与讨论图片继续按 50MB 限制。

每个项目对应专用 GitHub 组织中的一个私有仓库。网站保留项目介绍、归属、版本和讨论；GitHub 保存项目文件。成员使用现有网站账号即可，上传显示同步进度与状态，失败可重试，成功后清理服务器临时文件。

项目介绍公开，代码、README、文件下载和讨论沿用现有成员权限。网站代理访问私有项目，主要节省长期磁盘空间，下载仍使用服务器流量。项目删除先隐藏，禁止旧入口继续访问，保留记录与远端文件。

### 成员怎么使用

1. 在“专业项目库”点击“发布项目”，填写名称、介绍、课程 / 主题、技术标签和首版说明，再选择 ZIP。
2. 提交后显示上传进度和同步状态。首次同步成功后，项目才进入公开列表；等待和失败的项目可从“我的空间 → 我的项目”返回查看。
3. 打开项目，选择版本，点击文件名阅读 README / 代码，或下载该版本的完整项目包。较大的文本仅展示开头，完整内容通过下载查看。
4. 作者和管理员可“编辑与更新项目”。介绍单独保存，上传新 ZIP 生成新版本；新版本同步失败不会替换已发布版本。
5. 在项目讨论里提问、附图和回复。图片仍是最多 20 张、每条发布总计不超过 50MB。

同步失败会保留表单输入；临时包仍可用时可以“重新同步”，包过期或校验失败后需要重新上传。服务器暂存数量有限，队列已满会提示稍后再试。

同步在后台进行，文件较多时可能需要较长时间，可以先离开页面。已保存的相同文件会复用，失败重试不会重复写入这些文件；实际等待取决于网络与 GitHub 限额。

## PDF 按页提问

成员在现有资料库 PDF 阅读器当前页提问，可以附图并回复。阅读器可查看当前页问题或全部问题，从问题跳到对应页。

问题绑定具体文件和页码。换页后新问题记在新页；重新发布或换成另一份 PDF，不会把旧问题放到新文件上。原有普通资料评论继续保留。

提问者和管理员可以标记已解决或重新打开。访问权限、两层回复、图片限制和删除规则沿用现有讨论要求。

### 成员怎么使用

1. 打开一份 PDF 的站内预览，翻到有疑问的页码。
2. 在阅读器下方“PDF 按页提问”填写问题，可附图。换页后新问题绑定新的当前页；未提交的内容会保留。
3. 切换“当前页问题 / 全部问题”；在全部问题中点击页码跳回原页。
4. 提问者或管理员可标记“已解决”，也能“重新打开”；问题回复始终留在原问题的文件和页码下。

服务器会验证文件真实页数，只接受 1–10000 页范围内的合法页码。加密、损坏、超过 10000 页或验证超时的 PDF 不能绕过检查提问；页面会给出说明，原有资料预览和下载按原规则处理。
