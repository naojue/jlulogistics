# 产品需求与权限

## 定位

为几十至几百人的小型学习社区提供公开资料目录、成员专享下载与内部讨论。界面品牌为“吉大物流”，面向物流管理与计算机科学与技术双学位，聚焦物流问题、数据分析与代码实践。中文、深浅主题、手机适配。资料标题、简介、分类、标签、作者昵称、时间、文件类型与大小公开；邮箱、内部存储键、帖子、回复和资料评论不公开。

## 界面与主题

- 左上角展示吉大物流标识（JL 字母、供应链节点与毛体风格字标），点击返回资料库。
- 外观支持浅色、暗色和跟随系统；首次访问跟随系统，手动选择保存在当前浏览器，刷新及页面跳转后继续生效。浏览器限制本地存储时仍可切换。
- 深浅主题统一覆盖导航、资料卡片、登录注册、表单、讨论和管理界面，保持文字与状态提示清晰可读；手机页面不产生整体横向滚动。
- 暗色下标识有柔和光晕与缓慢掠过的闪光；浅色无闪光。系统开启减少动态效果时停用闪光动画。
- 切换外观不得清空业务表单输入；公开资料及成员权限遵循原权限矩阵。

## 账号规则

- 退出登录撤销当前会话并清除浏览器认证 Cookie，返回资料库并显示访客导航；旧会话不能继续访问私有入口。退出期间显示处理中并禁止重复提交，失败显示中文提示、保留当前页面与输入，并允许重试。
- 普通注册需要邮箱、至少 10 位密码、2–30 字昵称和 10–1000 字申请说明。邮箱验证后仍保持 PENDING，管理员审批后才 ACTIVE。
- role 独立为 MEMBER / ADMIN / SUPER_ADMIN；status 为 PENDING / ACTIVE / REJECTED / SUSPENDED；emailVerified 独立。
- 拒绝须填写原因，用户登录后可重新申请。停用立即撤销会话，内容保留。第一版不提供恢复停用账号功能。
- 重置密码通过邮件且撤销旧会话。初始管理员首次登录必须改密。
- 初始管理员由环境配置初始化，重复初始化不得覆盖现有密码；已有普通账号不得被初始化程序自动提升。
- 邮件不可用时，持有服务器维护权限的人可离线恢复唯一、ACTIVE 且已验证的超级管理员密码。工具先备份现有数据库，在同一事务内更新 Better Auth 密码散列、撤销该账号全部会话和旧密码重置链接、记录操作并要求登录后改密；不改变邮箱、角色、审批状态或邮箱验证结果，不提供网页恢复入口。
- 超级管理员生成绑定邮箱的一次性管理员邀请，七天有效、可撤销、只保存摘要。新用户注册验证邮箱后激活管理员身份；已有成员在成员中心兑换。失效邀请不激活身份，可联系超级管理员重新邀请。
- 超级管理员直接添加新管理员时发送激活链接；已激活成员可以直接提升。撤销管理员身份后变回普通成员并撤销会话。

## 内容规则

两区只有上传权限不同，浏览、预览和下载权限相同。所有成员资料、帖子、留言立即发布，管理采用事后处理。每份资料一个分类、多个现有标签、一份文档 / ZIP 或最多 20 张图片，所有文件总量上限 50×1024×1024 字节（不允许文档与图片混合发布）。支持 PDF、DOC/DOCX、PPT/PPTX、XLS/XLSX、TXT/MD、JPG/JPEG/PNG/WebP、ZIP。

资料搜索标题与简介，按最新时间排序并分页。帖子支持标题搜索与分类筛选。成员可编辑、删除自己的资料和帖子；更换资料文件通过重新发布实现。普通留言暂不提供编辑，只能删除后重发。正文和回复均为纯文本，可附 JPG/PNG/WebP 图片，每篇帖子、每条评论或回复最多 20 张、总计不超过 50MB；帖子编辑可移除旧图和追加新图，保留与新增图片一起计算限额；正文仍须满足原长度要求；仅允许同一主题下的两层回复。删除主留言隐藏其子回复和图片；删除主题隐藏全部讨论并禁止旧下载、预览和图片入口。

分类、标签由管理员创建、修改与删除，被内容使用的分类标签须先移除关联才能删除。管理删除需填写原因，所有管理操作留痕。删除内容采用软删除，原文件留存，便于备份和后续管理员恢复工具开发。

## 第一版边界

不做聊天、视频、付费、积分、站内消息和全文索引。成员中心显示最近 20 份资料、最近 20 篇帖子与最近 20 个项目；后台列表支持分页，邀请记录显示最近 100 条。

## 文件内容预览（2026-10-10）

预览与下载使用同一成员权限：访客与待审批用户不能读取文件、图片缩略图或正文。图片可查看原图，PDF 使用站内 PDF.js 阅读器（翻页、缩放与本页文字），TXT/MD 以纯文本显示（最多前 1MB）。DOCX 显示正文与表格；XLSX 显示工作表及已保存的单元格值；PPTX 显示各页文字。Office 采用内容预览，不保证还原排版、图表、内嵌图片和公式格式。最多显示 1000 个 Word 正文块、200 页幻灯片、20 个工作表，每表 200 行 / 100 列。

资料 ZIP 仅显示文件目录，服务器不解压。旧版 DOC/XLS/PPT、加密、损坏或内容过大的文件显示说明与下载入口，建议转换为 PDF 或现代 Office 格式。预览不调用第三方在线服务。两个资料区采用相同文件数量与总量规则。

## 专业项目与 PDF 按页提问（2026-10-11 实现，2026-10-12 更新运行状态）

本次范围为专业项目库、GitHub 项目存储、资料库 PDF 按页提问，页面、业务服务、数据迁移与隔离测试已完成。2026-10-12 用户确认：正式站点已升级，专用 GitHub 组织及 App 授权已接通，小项目与约 60MB 项目的上传、同步和下载成功；Nginx 项目上传配置检查与重新加载成功。上述实测不覆盖 200 MiB 极值或生产压力测试，PDF 按页提问的线上人工验收尚未收到用户确认。开发与验收记录见 tasks.md，用户操作说明见 next-update.md。

### 专业项目库与 GitHub

- 新增项目列表、搜索、课程 / 标签筛选、项目详情、发布、编辑、版本、讨论和后台管理。项目介绍包含名称、作者、课程 / 主题、技术标签及简介；文件目录、代码、README、运行说明和下载仅成员可见。
- 成员可以发布项目，作者和管理员可以编辑、更新或删除；项目的讨论支持现有文字、图片与两层回复体验。所有成员能力沿用现有邮箱验证、审批状态和初始密码要求，不新增项目发布审批。
- 网站保存项目介绍、归属、讨论、版本与同步状态；专用 GitHub 组织保存项目文件，每个项目一个私有仓库。同学无需 GitHub 账号，服务器授权访问 GitHub，不把凭证或私有下载直链交给浏览器。
- 首版通过源代码 ZIP 发布，每次 ZIP 实际大小及解压后文件实际字节总量分别不超过 200×1024×1024（200MB）；包内单个文件不超过 100×1024×1024（100MiB，GitHub 普通 Git 文件限制），最多 1000 个条目（文件与显式目录都计数）。解压总量按包内全部文件计算，不因排除导入的文件而放宽。校验安全路径、重复路径、符号链接和加密 / 损坏压缩包；依赖目录、编译产物、.git、密码配置、密钥和自动执行的 GitHub Actions 工作流不导入。代码和 README 以转义的纯文本显示，不渲染用户 HTML、不执行项目。200MB 仅用于专业项目包，原有资料和讨论图片维持 50MB。
- 上传后显示等待、同步、完成或失败，失败保留表单与可重试入口。首版尚未同步成功的项目仅作者和管理员可见；新版本失败时保留已发布版本。GitHub 远端提交与网站版本记录确认成功后清理临时文件，不在服务器长期保留项目源码。
- 作者和管理员更新时生成新版本与更新说明，成员可查看和下载历史版本。删除先软删除，项目文件、预览、下载和讨论入口立即不可访问；GitHub 私有文件与审计记录保留，不直接永久删除远端仓库。
- 原有资料库和图片存储保持原流程，不迁移现有文件。GitHub 项目存储主要节省长期磁盘；网站代理访问仍使用 VPS 流量。
- 未配置 GitHub 时保留项目库和已有介绍页面，但禁用上传并给出中文说明；不以演示仓库或模拟器替代生产存储。项目同步由独立后台进程处理，首次未成功的项目仅作者 / 管理员可见，等待与失败状态可从“我的项目”返回查看。

### 资料库 PDF 按页提问

- 在资料库 PDF 阅读器当前页新增提问，保存资料、具体文件、页码、提问者和正文；可附图片。第一页从 1 计数，翻页后新增问题绑定新的当前页。
- 阅读器显示“当前页问题”与“全部问题”；全部问题可跳到对应页。普通资料评论继续保留，未指定页码的旧评论不自动转换为按页问题。
- 问题支持现有两层回复，回复始终属于原问题和原页码。切换问题、回复或页码不得丢失未提交内容；失败保留文字和选图。
- 提问者及管理员可标记已解决或重新打开。删除自己的问题 / 回复及管理员管理遵循既有归属规则；管理员操作留痕。
- 问题绑定具体文件 ID，不只绑定资料 ID。删除资料、文件不可访问、删除问题或父回复时，相关问题、子回复和图片入口遵循现有隐藏与拒绝访问规则；不同文件或重新发布的 PDF 不继承旧页码问题。
- 访客、未验证、待审批、被拒绝、停用和未修改初始密码的账号不能查看或创建按页问题。服务端检查当前成员状态、资料 / 文件关系、PDF 类型与实际合法页码范围，不信任客户端声明的权限或页数。
- 按页提问支持服务端能够验证的 1–10000 页 PDF。页数解析受时间和内存限制；加密、损坏、超过 10000 页或验证超时的文件显示中文提示，不能绕过页码检查提问。文件的预览 / 下载继续按原权限和可用性处理。

本次不包含校园物流观察、课程学习路线、算法实验、同题多解或在线运行代码。项目包解包仅用于上述项目导入，不改变原有资料 ZIP 仅预览目录、不解压的规则。
